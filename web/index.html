安装后找不到命令？

Linux 把 ~/.local/bin 加入 PATH，当前终端可执行 export PATH="$HOME/.local/bin:$PATH"。Windows 把 %APPDATA%\npm 加入 PATH。

DSH 需要哪个 Node.js？

Node.js 22.19+（22.x）或 24+。可用本页的 Node.js 安装命令。

Windows 7 能用吗？

不能在 Windows 7 本机运行。请在受支持的系统上安装，通过远程桌面或 SSH 使用。

模型连接配置

镜像只负责安装。模型地址、协议和凭据使用公司提供的配置，密钥只保存在用户本机。
